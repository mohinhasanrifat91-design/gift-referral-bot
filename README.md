# Telegram Referral Competition Bot

1. @BotFather থেকে bot তৈরি করে token নিন।
2. Bot-কে Telegram group-এর Admin করুন এবং Invite Users permission দিন।
3. BOT_TOKEN, GROUP_ID এবং ADMIN_IDS সেট করুন।
4. `pip install -r requirements.txt`
5. `python bot.py`

Commands: /start /link /points /leaderboard /winners
প্রতি genuine নতুন member = 1 point। Top 3 হলো ১ম, ২য়, ৩য় winner।
